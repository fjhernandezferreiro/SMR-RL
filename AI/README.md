# Material didáctico: UT2 - Seguridad Física en Equipos y Servidores

Contenido en esta carpeta AI/:
- UT2_Seguridad_Fisica.md  (Documento fuente en Markdown, principal)
- UT2_Seguridad_Fisica.odt (Versión ODT editable; si necesita ajustes, convierta el MD a ODT en LibreOffice)
- UT2_Seguridad_Fisica.odp (Presentación ODP para clase; notas del presentador incluidas)
- checklist_1p.txt (Checklist imprimible; versión PDF puede generarse desde este archivo)
- registro_accesos.csv (Plantilla CSV de ejemplo para registro de accesos físicos)
- LICENSE.txt (CC BY-SA 4.0)
- assets/ (iconos e imágenes libres; si desea imágenes específicas, súbalas y las incluyo)

Uso:
1. Revise UT2_Seguridad_Fisica.md para contenido y ediciones.
2. Para generar ODT/ODP locales: abra el .md en LibreOffice (o convierta con pandoc) y exporte a ODT/ODP.
3. Los archivos .odt/.odp incluidos son marcadores/plantillas; si prefiere que suba binarios finales, solicítelo y los adjunto.
